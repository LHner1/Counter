# Wage Counter

A simple PyQt5 application that calculates your earnings in real-time based on your hourly wage.

## Features

- Input your hourly wage
- Start/stop tracking your earnings
- Reset button to clear earnings and timer
- Real-time calculation (updates every second)
- Earnings displayed in green with a "+" sign
- Timer display showing elapsed time in hours, minutes, and seconds

## Requirements

- Python 3.x
- PyQt5

## Dependencies

```
pip install PyQt5
```
